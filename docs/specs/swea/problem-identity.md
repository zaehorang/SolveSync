# SWEA 어느 문제를 푼 것인지 가려내기

> **Description**: 모든 문제가 같은 주소를 쓰는 SW Expert Academy 풀이 화면에서 지금 푼 문제가 무엇인지 어떻게 정하는지를, 화면과 저장소에서 관측되는 것만으로 정의한다. 정답을 세는 규칙은 [SWEA 정답 감지](accepted-detection.md)를 따른다.

## Goal
주소가 모든 문제에서 똑같은 화면에서도 방금 푼 문제가 어느 문제인지 정확히 가려내, 풀이가 엉뚱한 문제 자리에 쌓이지 않게 한다.

## Triggers
- 풀이 화면에서 무언가 달라질 때마다 지금 열려 있는 문제가 무엇인지 다시 확인한다
- 새로운 정답을 센 그 순간, 문제 번호와 문제 이름과 고른 언어를 함께 읽어 고정한다

## Inputs
- 화면 안에 들어 있는 문제 식별 값 — SW Expert Academy가 화면에 넣어 둔다. **주소에는 없다.** 사용자가 어떤 문제의 풀이 창을 열었는지로 정해진다.
- 화면 위쪽의 문제 제목 — SW Expert Academy가 정하며 "번호. 이름" 형태다.
- 고른 언어 — 사용자가 언어 고르는 곳에서 고른다.

## Outputs
- 문제 식별 값이 이 풀이가 어느 문제의 것인지를 정하는 기준이 된다. 같은 것을 이미 올렸는지 판단할 때도 이 값을 쓴다.
- 사람이 읽는 자리에는 화면에 보이는 문제 번호를 쓴다. 저장되는 파일 이름, 목록의 번호 칸, 커밋 설명이 여기에 해당한다.
- 문제 이름은 화면에 보이는 그대로 저장된다. 이름 앞에 붙은 번호와 마침표는 떼어낸다.
- 목록에서 문제로 돌아가는 링크는 풀이 화면 주소가 아니라 **그 문제의 소개 화면 주소**로 만들어진다. 풀이 화면 주소는 모든 문제가 같아서 링크로 쓸 수 없기 때문이다.

## Edge cases
- 화면 안의 문제 식별 값을 읽지 못하면 그 화면은 이 확장 프로그램의 대상이 아니게 되어, 정답을 받아도 아무 일도 일어나지 않는다.
- 제목이 "번호. 이름" 형태가 아니면 번호를 읽지 못한다. 이때는 제목 전체를 문제 이름으로 쓰고, 번호가 들어갈 자리에는 화면 안의 문제 식별 값이 대신 들어간다. 파일 이름도 그 값으로 시작한다.
- 제목을 화면에서 아예 찾지 못하면 저장하지 못하고 실패로 넘어간다. 그때 무엇이 보이는지는 [SWEA 풀이를 확보하지 못했을 때](source-failure.md)를 따른다.
- 풀이 창을 닫고 같은 주소로 다른 문제의 풀이 창을 연 뒤 정답을 받으면, 주소가 그대로여도 새로 연 문제로 저장된다. 앞서 푼 문제의 목록 줄은 그대로 남는다.
- 정답을 센 뒤 풀이 코드가 도착하기 전에 다른 문제로 옮겨 가면, 그 정답은 넘기지 않고 버린다. 옮겨 갔다가 같은 문제로 되돌아온 경우에도 버린다.
- 문제 번호는 앞을 영으로 채우지 않고 화면에 보이는 그대로 쓴다.
- 문제 이름이 대괄호로 시작해도 목록에서 링크가 깨지지 않게 그대로 읽히도록 처리된다.
- 문제 이름에 파일 이름으로 쓸 수 없는 문자가 있으면 밑줄로 바뀐 채 저장된다. 한글은 그대로 남는다.
- 난이도는 풀이 화면에 없으므로 가져오지 않는다. 난이도를 얻으려고 다른 화면을 대신 열어 보지도 않는다.

## Acceptance
- 어떤 문제에서 정답을 받은 뒤 저장소를 열면, 파일 이름이 그 문제의 화면 번호로 시작한다
- 풀이 창을 닫고 같은 주소로 다른 문제를 연 뒤 정답을 받으면, 새로 연 문제의 번호와 이름으로 기록이 한 줄 남는다
- 그렇게 두 문제를 연달아 푼 뒤 목록 문서를 열면, 먼저 푼 문제의 줄이 그대로 남아 있다
- 목록 문서에서 문제 제목의 링크를 누르면 그 문제의 소개 화면이 열린다
- 목록 문서를 열면 난이도 칸이 없다
- 이름이 대괄호로 시작하는 문제를 푼 뒤 목록 문서를 열면, 제목이 대괄호를 포함해 그대로 보이고 링크도 동작한다

## 열린 질문
- 제목이 "번호. 이름" 형태가 아니어서 번호를 읽지 못한 경우, 화면 안의 문제 식별 값이 파일 이름 앞에 붙는다. 사람이 읽기 어려운 값인데 이 자리에 그대로 노출하는 것이 의도된 결정인가?
- 그 경우 문제 이름 자리에는 제목 전체가 들어가므로 번호가 이름 안에 한 번 더 들어갈 수 있다. 이것이 의도된 결과인가?
- 난이도를 가져오지 않기로 한 것은 화면에 없기 때문인데, 사용자가 목록에서 난이도를 보고 싶어 하는 요구가 있는가?
